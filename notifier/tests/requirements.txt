# Notifier test environment.
#
# A deliberate subset of the root pyproject, same rule as settler/tests: the
# notifier imports nothing from web3 / fastapi / celery, and installing them
# would add minutes to every run for no coverage. Pins MUST match the root
# pyproject.toml where a package appears in both.
#
# aiogram was absent through Week 4, and that absence was the point of the
# design: the delivery loop, the retry curve, the DLQ and the rate limiter were
# all tested without a Telegram client existing, through the `MessageSender`
# protocol. Week 5 added `notifier/telegram.py`, so this file gained the one
# line below and not one of those tests changed — which is the claim the
# protocol was written to make good on.
#
# Everything except `test_aiogram_sender.py` still runs without it: that module
# opens with `pytest.importorskip("aiogram")`, so a deployment that installs
# only the delivery dependencies gets a skip rather than a collection error.
#
# `redis` IS here, unlike in settler/tests, because the rate limiter's Redis
# path is real code with a Lua script in it — the one thing in this package that
# cannot be verified by reading. The tests that use it skip themselves when
# REDIS_URL is unset; docker-compose.test.yml sets it.
#
